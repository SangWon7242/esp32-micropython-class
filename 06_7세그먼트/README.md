# 06. 7세그먼트 (1자리 디지털 튜브)

막대 전구 8개로 만든 작은 화면에 0부터 9까지 숫자를 띄웁니다.

---

## 실습 목표

74HC595(도우미 칩)를 써서 **핀 3개로 LED 8개**를 제어하고, 켤 막대를 0과 1 여덟 개로 적는다.

---

## 준비물

- ESP32 메인보드 1개
- 74HC595N 칩 1개
- 1자리 디지털 튜브 1개
- 220Ω 저항 8개
- 브레드보드 1개
- 점퍼선 여러 가닥
- Micro USB 케이블 1개

---

## 회로 연결표

| 연결 목적 | 출발(부품/핀) | 도착(부품/핀) | 설명 |
|---|---|---|---|
| 데이터 보내기 | ESP32 IO5 | 74HC595 SI | 켤지 말지를 하나씩 올려 둠 |
| 한 칸 밀기 | ESP32 IO18 | 74HC595 SCK | 누를 때마다 한 칸씩 들어감 |
| 한꺼번에 내보내기 | ESP32 IO23 | 74HC595 RCK | 8칸이 다 차면 한 번에 출력 |
| 막대로 출력 | 74HC595 Q0~Q7 | 220Ω → 디지털 튜브 a~dp | 저항 8개 필요 |
| 되돌아오기 | 디지털 튜브 공통 음극 | ESP32 GND | 막대들의 (−) |

### 연결 체크 포인트

- 74HC595N의 **반달 모양 홈**이 배선도와 같은 방향인가요?
- 디지털 튜브의 **점(dp)이 오른쪽 아래**에 오도록 꽂혔나요?
- 220Ω 저항 8개를 Q0~Q7 **각각**에 달았나요?
- 디지털 튜브의 마이너스 다리가 GND로 가나요?

---

## 코드 흐름

1. `SEGCODE` 목록에 0~9의 막대 코드를 담아 두기
2. SI · SCK · RCK 세 핀을 출력으로 준비
3. `hc595_shift()` 로 8비트를 한 칸씩 밀어 넣고 마지막에 내보내기
4. `for num in range(10)` 으로 0부터 9까지 보여 주기

## 알아 두기

**왜 도우미 칩을 쓸까요?** 막대가 8개면 선도 8개라 ESP32 핀을 다 써 버립니다. 74HC595를 쓰면 **핀 3개**면 끝납니다.
