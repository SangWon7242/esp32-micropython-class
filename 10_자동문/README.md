# 10. 다가가면 열리는 자동문

**1부에서 초음파 센서만 먼저 익히고**, **2부에서 서보(문)와 OLED(화면)를 더해** 자동문을 완성합니다.

> 🧑‍💻 **학생은 [개별 트랙 진행표](TRACK.md)** 를 보면서 내 속도로 진행하세요.
> 👩‍🏫 **선생님은 [교사용 지도안(110분)](TEACHING.md)** 을 함께 보세요 — 시간 흐름, 핵심 질문, 예상 오류 대응이 들어 있습니다.

---

## 실습 목표

초음파로 잰 거리를 `if` 로 판단해 서보(문)와 OLED(화면)를 함께 제어한다.

---

## 준비물

- ESP32 메인보드 1개
- 초음파 센서(HC-SR04) 1개
- 서보모터 1개
- OLED 화면 1개
- F-F · M-F 듀폰선 여러 가닥
- Micro USB 케이블 1개
- (추가 미션용) 빨강 LED 1개 · 220Ω 저항 1개

---

## 회로 연결표

| 연결 목적 | 출발(부품/핀) | 도착(부품/핀) | 설명 |
|---|---|---|---|
| 초음파 신호(쏘기) | ESP32 IO13 | 초음파 Trig | 소리를 쏘라고 보내는 신호 |
| 초음파 신호(듣기) | ESP32 IO12 | 초음파 Echo | 메아리가 돌아온 시간을 알려 줌 |
| 서보 신호 | ESP32 IO4 | 서보 주황색 선 | 문의 각도를 정하는 PWM 신호 |
| OLED 신호 | ESP32 IO22 | OLED SCL | I2C 신호선 |
| OLED 데이터 | ESP32 IO21 | OLED SDA | I2C 데이터선 |
| 전원 | ESP32 5V | 초음파 Vcc · 서보 빨강 · OLED VCC | 셋 다 5V |
| 접지 | ESP32 GND | 초음파 GND · 서보 갈색 · OLED GND | 셋 다 GND |
| (추가) LED | ESP32 IO26 | 220Ω → LED(+) → GND | 문이 열리면 켜지는 불 |

### 연결 체크 포인트

- **1부에서는 초음파 센서 4선만** 연결합니다. 서보와 OLED는 2부에서 더합니다.
- 초음파 센서는 **반드시 5V** 입니다. 3.3V로는 잘 동작하지 않습니다.
- **Trig는 IO13, Echo는 IO12** — 두 선을 바꿔 꽂으면 숫자가 안 나옵니다.
- ⚠️ 초음파 센서는 **전원을 끈 상태에서** 연결하세요. 꼭 켠 채로 연결해야 한다면 **GND를 가장 먼저** 꽂습니다.
- 서보는 08 챕터, OLED는 09 챕터와 **똑같은 자리**입니다.
- ⚠️ 화면을 쓰려면 **`ssd1306.py`** 를 보드에 올려야 합니다 → [lib/README.md](../lib/README.md)
- 세 부품의 핀(IO13·IO12 / IO4 / IO22·IO21)은 **하나도 겹치지 않습니다.**

## 코드 흐름

1. **1부 ①** — 초음파 센서만 연결하고, 거리 숫자가 창에 제대로 찍히는지 확인
2. **1부 ②** — `if d < 15:` 로 '가까이 왔다'를 판단해 `print` 로 알려 주기 (연습)
3. **2부 ①** — `print` 자리에 서보(문)를 넣어, 가까워지면 문이 열리게
4. **2부 ②** — OLED를 더해 `DOOR OPEN` / `DOOR CLOSE` 를 화면에 표시
5. `get_distance()` 와 `show()` 두 함수를 만들어 두고 이름만 불러 쓰기

## 미션

### 1부 연습 미션 · 가까이 오면 알려 주기

문을 만들기 전에, **판단하는 연습**부터 합니다.
거리가 15cm보다 가까워지면 창에 `가까워요!` 라고 함께 찍어 주세요.

> 💡 `if d < 15:` 아래 줄은 **한 칸 더 들여쓰기** 해야 합니다. 들여쓰기가 '어디까지가 if 안인지'를 정합니다.

> 🔭 여기서 `print` 자리에 '문 열기'를 넣으면 바로 2부의 자동문이 됩니다.

정답 → [`practice_near.py`](code/practice_near.py)

### 미션 · 대기 화면에도 지금 거리를 보여 주기

## 알아 두기

**초음파가 거리를 재는 방법** — Trig 핀에 10마이크로초짜리 신호를 주면 센서가 사람 귀에 안 들리는 높은 소리를 쏩니다. 소리가 물체에 부딪혀 돌아오는 동안 Echo 핀이 켜져 있고, 그 시간을 재면 거리를 알 수 있습니다. 박쥐가 어두운 동굴에서 길을 찾는 방법과 같습니다.

**계산식** — 소리는 1초에 340m를 갑니다. 갔다가 돌아왔으니 시간을 `// 2` 로 반 나눈 뒤 소리 속도를 곱하면 cm 거리가 나옵니다.

**측정 범위** — 2cm ~ 4m, 센서 정면 **15° 안쪽**. 넓고 평평한 면이 가장 잘 잡힙니다.

**서보 각도** — `duty_u16(1638)` 이 닫힌 자리, `duty_u16(8100)` 이 열린 자리입니다 (08 챕터와 같음).

**화면에는 영어와 숫자만** — 기본 글꼴에 한글이 없어서 한글을 넣으면 깨져 보입니다.
