## 이렇게 공부합니다

| 하는 것 | 안 하는 것 |
|---|---|
| 깃허브 코드를 **복사해서** 씁니다 | 한 글자씩 다 치지 않습니다 |
| 복사한 코드를 **읽고 질문에 답합니다** | 읽지 않고 넘어가지 않습니다 |
| 결과를 **먼저 예측**하고 실행합니다 | 일단 돌려 보고 넘기지 않습니다 |
| 고장난 코드의 **원인을 직접 찾습니다** | 바로 정답을 보지 않습니다 |

### 한 가지 약속

> **복사한 코드를 "이게 무슨 뜻인지" 말할 수 없으면 다음으로 넘어가지 마세요.**
> 막히면 **2분만 혼자** 해 보고, 그래도 안 되면 선생님을 부르세요.

## 코드 가져오는 법

1. 이 저장소에서 **`10_자동문/code`** 폴더를 엽니다
2. 슬라이드에 적힌 **파일 이름**을 찾아 엽니다
3. 오른쪽 위 **복사 단추**를 눌러 코드 전체를 복사합니다
4. PyCharm 의 **`main.py`** 를 열고 → `Ctrl+A` 로 전부 지우고 → 붙여넣기
5. **Run** 을 눌러 보드에 올리고 결과를 확인합니다

> 슬라이드의 검은 코드 카드 **맨 위에 파일 이름**이 적혀 있습니다.
> 예: `복사할 파일 · step1_distance.py`

## 읽기 체크 문제 (정답은 슬라이드에서)

### 읽기 체크 ① — `step1_distance.py` 를 읽고

1. 소리를 **쏘는** 핀은 `trig` 와 `echo` 중 어느 것인가요? 몇 번 핀이죠?
2. 함수 안에서 **시간을 적어 두는 줄**은 몇 개인가요?
3. `t = t // 2` 를 지우면 숫자가 어떻게 달라질까요?

### 읽기 체크 ② — `step3_auto_door.py` 를 읽고

1. 문이 **열려 있는 시간**은 몇 초인가요? 어느 줄을 보면 알 수 있죠?
2. `show()` 는 한 바퀴에 **몇 번** 불리나요?
3. `if d < 15:` 안에 들어 있는 줄은 **몇 줄**인가요?

> 답을 **공책에 먼저 적은 뒤** 슬라이드를 넘기세요.
