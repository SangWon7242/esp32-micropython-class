# 11. 버튼으로 켜는 선풍기

07장에서 만든 선풍기에 버튼을 하나 달아, 누르면 켜지고 다시 누르면 꺼지게 만듭니다.

---

## 실습 목표

버튼이 **눌리는 순간**을 잡아내고, 켜짐·꺼짐 상태를 변수에 기억해 두었다가 뒤집는다.

---

## 준비물

- ESP32 메인보드 1개
- 팬 모터 모듈 1개 (07장과 같은 것)
- 버튼 1개
- 브레드보드 1개
- 듀폰선 여러 가닥
- Micro USB 케이블 1개
- 외부 전원 (AA 건전지 6개) — 모터가 USB 전류만으로는 모자랍니다

---

## 회로 연결표

| 연결 목적 | 출발(부품/핀) | 도착(부품/핀) | 설명 |
|---|---|---|---|
| 방향 제어 1 | ESP32 IO13 | 모터 모듈 IN+ | 07장 그대로 |
| 방향 제어 2 | ESP32 IO12 | 모터 모듈 IN- | 07장 그대로 |
| 버튼 | ESP32 IO14 | 버튼 한쪽 다리 | 새로 더하는 선 |
| 버튼 접지 | ESP32 GND | 버튼 반대쪽 다리 | 누르면 GND 와 이어짐 |
| 모터 전원 | ESP32 5V · GND | 모터 모듈 V · G | 07장 그대로 |

### 연결 체크 포인트

- **07장 배선은 그대로 둡니다.** 버튼 두 가닥만 새로 더하면 됩니다.
- 버튼은 `Pin.PULL_UP` 으로 읽습니다. 그래서 **평소엔 1, 누르면 0** 입니다.
- 버튼 다리는 대각선끼리 이어져 있습니다. **마주 보는 두 다리**를 쓰세요.
- 모터는 전류를 많이 먹습니다. **외부 전원을 꼭 연결**하세요.

## 알아 두기

**왜 '눌리는 순간'을 잡아야 하나** — 사람이 버튼을 한 번 누르는 데 0.2초쯤 걸립니다. 그 동안 코드는 수십 번 돌면서 '눌림'을 계속 읽습니다. 그래서 `if button.value() == 0:` 만 쓰면 한 번 눌러도 켜졌다 꺼졌다를 수십 번 반복합니다.

바로 전 상태를 `last` 에 기억해 두고, **1 에서 0 으로 바뀐 그 한 번**만 잡으면 해결됩니다. 이것을 '엣지(모서리)를 잡는다'고 합니다.

```python
now = button.value()
if last == 1 and now == 0:    # 바뀐 순간
    ...
last = now                    # 기억해 두기
```

**PULL_UP 이 무엇인가** — 버튼을 안 누르면 핀이 아무 데도 연결되지 않아 값이 멋대로 흔들립니다. `Pin.PULL_UP` 을 쓰면 ESP32 안에서 핀을 1 쪽으로 살짝 당겨 줍니다. 그래서 **평소엔 1, 버튼을 누르면 GND 와 이어져 0** 이 됩니다.

**`not` 은 뒤집기** — `on = not on` 은 True 면 False 로, False 면 True 로 바꿉니다. 스위치를 뒤집는 것과 같습니다.

**다음 장 예고** — 12장에서는 버튼 자리에 적외선 리모컨을 넣습니다. 버튼을 그대로 두면 **버튼으로도 리모컨으로도** 켜지는 선풍기가 됩니다.
