# 13. 바람 세기 조절

12장 선풍기의 바람을 네 단계로 조절하고, 지금 몇 단계인지 OLED 화면에 보여 줍니다.

---

## 실습 목표

`PWM` 의 `duty` 로 모터 세기를 단계별로 바꾸고, 리모컨 값과 단계를 **표(딕셔너리)** 로 이어 화면에 함께 표시한다.

---

## 준비물

- ESP32 메인보드 1개
- 팬 모터 모듈 1개 (07~12장과 같은 것)
- 적외선 리모컨 + 수신기 1세트 (12장 그대로)
- OLED 화면 1개
- 버튼 1개 (추가 미션용)
- 브레드보드 1개
- 듀폰선 여러 가닥
- 외부 전원 (AA 건전지 6개)

---

## 회로 연결표

| 연결 목적 | 출발(부품/핀) | 도착(부품/핀) | 설명 |
|---|---|---|---|
| 속도 제어 | ESP32 IO13 | 모터 모듈 IN+ | **PWM 으로 바뀝니다** |
| 방향 | ESP32 IO12 | 모터 모듈 IN- | 0 으로 고정 (한 방향) |
| 리모컨 신호 | ESP32 IO5 | 수신기 S | 12장 그대로 |
| 화면 신호 | ESP32 IO22 | OLED SCL | 새로 더하는 선 |
| 화면 데이터 | ESP32 IO21 | OLED SDA | 새로 더하는 선 |
| 버튼 | ESP32 IO14 | 버튼 한쪽 다리 | 11장 그대로 (추가 미션용) |
| 전원 | ESP32 5V · GND | 모터 · 수신기 · OLED | 모두 함께 |

### 연결 체크 포인트

- **배선은 12장 그대로**입니다. OLED 네 가닥만 새로 꽂으면 됩니다.
- IO13 은 `Pin` 이 아니라 **`PWM`** 으로 만듭니다. 핀은 그대로지만 코드가 달라집니다.
- IO12 는 `value(0)` 으로 한 번만 고정해 둡니다. 한 방향으로만 돌릴 것이기 때문입니다.
- ⚠️ 라이브러리 **2개** 필요 — `irrecvdata.py` · `ssd1306.py`
- 모터는 전류를 많이 먹습니다. **외부 전원을 꼭 연결**하세요.

## 알아 두기

**PWM 이 무엇인가** — 디지털 핀은 켜짐(1)과 꺼짐(0) 두 가지뿐입니다. 그런데 아주 빠르게 켰다 껐다를 반복하면, 켜 있는 시간의 비율만큼 세기가 조절됩니다. `duty(400)` 은 1023 중 400 만큼 켜 두라는 뜻입니다. 02장 숨쉬는 LED 에서 밝기를 조절했던 그 방법입니다.

**모터는 너무 낮으면 안 돕니다** — `duty(100)` 처럼 작으면 소리만 나고 날개가 안 돌 수 있습니다. 교실에서 직접 숫자를 바꿔 보며 **돌기 시작하는 값**을 찾아보세요.

**표(딕셔너리)를 쓰는 이유** — 리모컨 버튼이 네 개면 `if` 를 네 번 써야 합니다. 버튼이 늘면 코드도 길어집니다. 표에 적어 두면 `if v in KEYS:` 한 줄이면 되고, 버튼을 늘릴 때 표에 한 줄만 더하면 됩니다.

```python
KEYS = {"0xff4ab5": 0, "0xff6897": 1, ...}
if v in KEYS:          # 표에 있으면
    level = KEYS[v]    # 몇 단계인지 꺼내기
```

**`apply()` 로 묶은 이유** — 단계를 바꿀 때 해야 할 일이 세 가지입니다. 모터 세기 바꾸기, 화면 다시 그리기, 창에 찍기. 이것을 한 함수에 묶어 두면 리모컨으로 바꾸든 버튼으로 바꾸든 `apply(level)` 한 번만 부르면 됩니다.

**화면에는 영어와 숫자만** — 기본 글꼴에 한글이 없어서 한글을 넣으면 깨져 보입니다.
